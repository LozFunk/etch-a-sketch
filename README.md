# Etch-a-Sketch

A web-based Etch-a-Sketch drawing tool built with HTML, CSS, and JavaScript. Users can create a customizable grid and draw by hovering over the squares, gradually increasing their darkness for a shading effect.

---

# Features

Dynamic grid size: Users can choose the number of squares per side (1–100).

Hover drawing: Move the mouse over squares to “draw.”

Gradual shading: Each hover increases the opacity of the square for a layered drawing effect.

Reset and redraw: Change grid size anytime by clicking the “Grid Size” button.
